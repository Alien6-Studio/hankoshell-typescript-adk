# 0.7.1 — Consolidated application integration

Milestone: https://github.com/Alien6-Studio/hankoshell-typescript-adk/milestone/2

## Product outcome

Keep the application-session integration compatible with the current sign-in and account components. Applications retain shared sessions across replicas and restarts, reliable sign-out, explicit access denials and approved organization selection introduced in 0.7.0.

This version consolidates the reviewed dependency and delivery changes from PRs #15 and #18. Node 22 and 24 remain supported. Business identity binding and application permissions retain their existing contract.

## Qualification and delivery

Qualification covers both supported Node versions, the packaged server and React entrypoints, strict application-access fixtures, and the real OIDC/Auth.js/PostgreSQL reference with independent instances, concurrent renewal, restart and revocation. Required checks and the signed source/output attestation gate the protected release workflow.

Client implementations consume the qualified public 0.7.1 release after publication. Public 0.7.0 tags and artifacts remain immutable.
